# DeepSeek Chat - 浏览器端AI聊天工具

一个基于 **DeepSeek API** 的纯前端聊天界面，支持文件上传、代码高亮、流式输出，并可分析前端代码文件的安全风险。

---

## 功能特点

- 🤖 **与 DeepSeek 模型对话**：使用 DeepSeek API 进行多轮对话。
- 📤 **文件上传分析**：支持拖拽或选择上传 HTML / JS / CSS / TXT 等文件，工具会自动解析并提取可见文本，可让模型对文件内容进行功能、安全、兼容性分析。
- 🖥️ **代码高亮**：AI 回复中的代码块会自动语法高亮（基于 `highlight.js`）。
- ⏯️ **流式输出**：实时显示模型生成内容，支持中途停止生成。
- 💾 **聊天历史管理**：本地保存多个对话，支持搜索、切换和删除。
- 🌓 **深色/浅色主题**：一键切换。
- 📋 **导出对话**：可将对话导出为 Markdown 文件。
- 🔒 **隐私保护**：API Key 仅保存在本地浏览器，不会上传到任何第三方服务器。

---

## 技术栈

- 纯 HTML + CSS + JavaScript（无前端框架）
- [Marked.js](https://marked.js.org/) - Markdown 解析
- [Highlight.js](https://highlightjs.org/) - 代码语法高亮
- Fetch API + ReadableStream - 流式 API 请求
- LocalStorage - 本地数据持久化

## 快速开始

### 1. 获取 DeepSeek API Key

前往 DeepSeek 开放平台注册并获取 API Key。

### 2. 下载项目文件

将仓库中的 `deepseek修改版.html` 文件保存到本地，或直接克隆仓库。

### 3. 打开应用

直接用浏览器打开该 HTML 文件即可，无需搭建服务器。

### 4. 配置 API Key

- 点击右下角 **⚙ 设置**
- 粘贴你的 **API Key**
- （可选）勾选“在此浏览器中记住 API Key”
- 点击 **保存**

### 5. 开始聊天

在输入框中输入问题，或拖拽/上传文件进行分析。

## 使用说明

| 按钮 / 操作         | 说明                          |
| ------------------- | ----------------------------- |
| **＋ 新聊天**       | 创建一个新对话                |
| **搜索框**          | 按标题搜索历史聊天            |
| **📎 附件**        | 选择文件上传（最多5个，每个≤2MB） |
| **⇩ 导出**         | 导出当前对话为 `.md` 文件     |
| **🌓 主题**        | 切换深色/浅色主题             |
| **⚙ 设置**        | 配置 API Key、模型等          |
| **■ 停止生成**     | 中断 AI 回复的流式输出        |

### 文件分析

支持的文件格式：`html`, `htm`, `js`, `css`, `txt` 等纯文本文件。

- HTML 文件会被解析出**页面标题**和**可见文本**
- 其他文件会以纯文本形式提取前 12 万字符（可配置）

模型将分析文件内容并给出安全、功能、重构等建议。

## 自定义配置

在设置面板中可修改以下参数：

```javascript
{
  apiKey: '',                                    // DeepSeek API 密钥
  endpoint: 'https://api.deepseek.com/chat/completions',  // API 地址
  model: 'deepseek-v4-pro',                      // 模型名称（代码内默认）
  systemPrompt: '你是专业的前端工程师和安全审查助手...',  // 系统提示词
  rememberKey: false                             // 是否记住 API Key
}
